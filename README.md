# Autopilot · Aerodrome LP landing

Static landing page for Autopilot, automated liquidity for Aerodrome LPs, powered by Harvest.

- `/` — landing page (`index.html`)
- `/checklist` — Aerodrome requirements checklist (`checklist/index.html`, linked from the footer only)
- `assets/` — favicon, OG image (`og-source.html` renders `og.png`), token icons from Aerodrome's token asset CDN

No build step. Run locally with `node serve.cjs` (clean URLs on http://localhost:4321).

Demo figures are illustrative, anchored to Aerodrome and price data as of 2026-10-02.
